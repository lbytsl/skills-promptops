# Security Policy

English · [简体中文](SECURITY.zh-CN.md)

Do not disclose an unresolved issue publicly if it can bypass safety boundaries, cause unauthorized agent actions, or expose sensitive information. Report it privately through GitHub Security Advisories with a minimal reproduction, impact assessment, and suggested mitigation.

Methodology defects, ordinary prompt-injection examples, and non-sensitive benchmark improvements may be submitted through public issues. Supported versions are declared in each release.
