# Roadmap

English · [简体中文](roadmap.zh-CN.md)

## v0.2 — Foundation

- Standardize portable Skill metadata and progressive loading.
- Add reliability dimensions and scenario profiles.
- Publish the first machine-readable fixtures.
- Complete governance and release documentation.

Exit criteria: Skill validation passes, core links resolve, and every supported intent has an example.

## v0.3 — Community Dataset

- Establish a Prompt failure taxonomy.
- Expand to 50+ bilingual fixtures.
- Create RAG, agent, coding, and structured-output subsets.
- Introduce a fixture contribution checklist.

Exit criteria: every fixture has provenance, license, expected verdict, and rationale; at least five external contributors participate.

## v0.4 — Reproducible Evaluation

- Fix model, parameters, repetition count, and aggregation methods.
- Separate static quality, task success, stability, and safety failure rates.
- Publish the first cross-model report and raw run records.

Exit criteria: a third party can reproduce the core results from public instructions.

## v0.5 — Prompt Quality Spec RC

- Publish JSON Schema and normative terminology.
- Collect feedback from agent and framework maintainers.
- Define compatibility and extension mechanisms.

## v1.0 — Open Standard Skill

- Stabilize input and output contracts.
- Publish migration guidance and a long-term version policy.
- Release Prompt Quality Spec 1.0.
- Provide integrations for at least two external agent ecosystems.
